# NVDA demo dataset provenance

This dashboard bundles historical NVIDIA stock data for first-run demonstration. The demo is **not** the CSV from the linked Kaggle page.

- CSV origin: https://github.com/FarhanAli97/NVIDIA-NVDA-Stock-Data-1999-to-December-2024
- Original filename: NVIDIA (NVDA) From 1999 To Dec-2024.csv
- Original published by: FarhanAli97
- Historical coverage: Jan 22, 1999 through Nov 29, 2024
- Recorded daily observations: 6,507
- Repository license: Apache License 2.0 (https://github.com/FarhanAli97/NVIDIA-NVDA-Stock-Data-1999-to-December-2024/blob/main/LICENSE)
- Underlying history is described in the source as coming from Yahoo Finance.
- Original numeric CSV rows have not been intentionally modified; the filename has been changed to clarify its demo scope.

To use the user's requested Kaggle dataset, download https://www.kaggle.com/datasets/caesarmario/nvidia-stock-historical-price and import its CSV using the dashboard's Import CSV button.

Do not infer a live market quote, current trading price, or consistent adjustment methodology from this historical demo.
